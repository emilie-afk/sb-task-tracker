Export old tracker data from this browser

The old Task Tracker stored tasks and KPI scorecards only in each browser. This page reads that saved data from this browser only and downloads it as a file on this computer.

  • Nothing is uploaded or sent anywhere, and nothing is erased from this browser.
  • Old passwords, roles and brand permissions are not exported.
  • Give the file only to a Task Tracker administrator, who imports it through the private import screen. Do not share it in public places or commit it to Git.
